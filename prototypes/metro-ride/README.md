# Metro ride prototype

A single-file prototype of the next version of the site: the portfolio as a metro line from Pune to Toronto.

It is not part of the build and is not deployed. `index.html` is a page fragment (no doctype or head), written for a preview tool, and the images it uses are in `img/`.

Before this becomes the real site: remove the "Test" panel and the `window.__ride` test hook, switch the weather to a live source, and host the fonts locally.
